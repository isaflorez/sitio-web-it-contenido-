# Sitio web corporativo I&T – Módulo de contenido y UX-UI

Repositorio del módulo de **contenido, casos de éxito y manual de usuario** del sitio web de **I&T Investigación y Tecnología SpA**, desarrollado como parte de una práctica profesional.

## Descripción

I&T es una empresa chilena de base tecnológica que desarrolla soluciones con inteligencia artificial, visión artificial, robótica, Internet de las Cosas (IoT) y automatización.

Este módulo se encarga de que el sitio tenga contenido claro, atractivo y bien documentado para presentar la empresa, sus servicios y sus proyectos.

## Objetivo del módulo

Diseñar y producir el contenido y la experiencia de usuario de las secciones informativas del sitio (**Quiénes somos, Servicios, Casos de éxito y Contacto**), asegurando coherencia visual, claridad y accesibilidad, y documentar el sitio en un manual de usuario.
